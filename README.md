# LinkedIn Profilpositionierung

Dieses Plugin erstellt für Kunden fünf strategisch unterschiedliche LinkedIn Profilslogans mit einer klaren Empfehlung sowie eine vollständige LinkedIn Infobeschreibung.

Es positioniert eine Person passend als Unternehmensgesicht, Fachexperte oder in einer Kombination aus beidem. Aussagen werden nur verwendet, wenn sie durch Kundendaten oder freigegebene Quellen belegt sind.

## Installation auf einem Mac

```text
/Applications/ChatGPT.app/Contents/Resources/codex-cli/CodexCLI.app/Contents/MacOS/codex plugin marketplace add PKHRW/linkedin-profilpositionierung-plugin
```

```text
/Applications/ChatGPT.app/Contents/Resources/codex-cli/CodexCLI.app/Contents/MacOS/codex plugin add linkedin-profilpositionierung-team@pw-team-plugins
```

Anschließend die ChatGPT Desktop App vollständig schließen, neu öffnen und einen neuen Chat starten.

Die ausführliche Nutzung, Kundendaten Checkliste und Qualitätskontrolle stehen in [MITARBEITERIN-ANLEITUNG.md](MITARBEITERIN-ANLEITUNG.md).
